# PakKom LJK Scanner v1.7.0 — Answer Key & Auto Grading

Fitur: kelola kunci per format (20 A-D, 30 A-E, 50 A-E), simpan lokal SharedPreferences, scan lembar kunci lalu tinjau di editor, koreksi otomatis, skor 0-100 bila seluruh kunci dan jawaban jelas. Jika jawaban ? atau kode peserta meragukan, nilai final ditahan. OMR/CameraX dan aset koordinat dari v1.6.9 tidak diubah.

**Catatan:** Saat format diganti di beranda, buka ulang beranda agar ringkasan jumlah kunci terbarui. Pemindaian kunci membuka editor dan tidak otomatis mengesahkan nilai.

Unggah seluruh isi folder ke root repository GitHub. Build Android melalui GitHub Actions. Build belum dijalankan di lingkungan ini.
